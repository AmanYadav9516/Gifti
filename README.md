# 🎁 Gifti — Interactive Digital E-Gift Experience
### *Crafted with ❤️ by AAYU SOLUTION*

**Gifti** is a next-generation interactive e-gift and memory sharing platform. Instead of ordinary greeting cards or text messages, senders can craft deeply emotional, cinematic, interactive digital journeys for their loved ones.

---

## ✨ Key Features

- 🇮🇳 **Bilingual Support (हिन्दी & English)**: Complete bilingual interface and message writing across all screens.
- 🤖 **AI Smart Message Co-pilot**: Powered by Google Gemini AI with 7 emotional tones (*Emotional, Funny, Cute, Romantic, Poetic/Shayari, Deep, Short & Sweet*).
- 🌹 **7 Interactive 3D Gifts**:
  - **Magic Blooming Rose**: Touch/swipe to scatter romantic petals.
  - **Mystery Shaking Box**: Haptic shaking vibration with confetti & light explosion.
  - **Sweet Chocolate Box**: Interactive unwrap & sweetness bite.
  - **Birthday Special Cake**: Interactive candle extinguishing with celebration fireworks.
  - **Sparkling Diamond Ring**: Shimmering diamond gleam.
  - **Sacred Golden Rakhi**: Traditional divine glow with sacred blessings aura.
  - **Lush Flower Bouquet**: Vibrant floral bloom celebration.
- 🌌 **6 Cinematic Atmospheres (Worlds)**:
  - *Deep Galaxy & Starlight*
  - *Enchanted Rose Garden*
  - *Cozy Rainy Window*
  - *Golden Mountain Sunrise*
  - *Sparkling Holiday Celebration / Snow*
  - *Royal Indian Festive (Diya & Rangoli)*
- 💌 **Wax-Sealed Mystery Envelope**: Break the glowing wax seal to unfold the secret surprise.
- ✨ **Magic Scratch Glow Reveal**: Dark night screen where moving fingers reveal glowing words.
- 🎙️ **Voice Note inside Gift**: Record 10–30s of your real voice with live waveform visualizer.
- 📸 **Cinematic Memory Album**: 1–5 photo memories carousel with smooth Ken-Burns transitions.
- 🔗 **Zero-Friction Sharing**: 1-Click WhatsApp Share, SMS, QR Code, and Direct Link copy. Receivers open gifts immediately in any browser with **zero app installation required**!
- 📲 **Viral APK Promotion Banner**: Promotes official Android APK installation by **AAYU SOLUTION**.

## 🚀 Quick Start & Installation

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS (Glassmorphism, 3D CSS transforms, Custom Animations)
- **AI Engine**: Google Gemini API
- **Audio Engine**: Web Audio API (Synthesized chimes, fanfares, heartbeats, candle soundfx)
- **Visual FX**: HTML5 Canvas Particle Engine + Canvas-Confetti
- **Link Compression**: `lz-string` URL-safe state serialization
